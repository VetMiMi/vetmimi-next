# Brand icon

`icon.svg` is the source of the site icon: cream "Vm" in Fraunces 500 on Deep Indigo (`#494c6d`) with a Poppy Coral (`#db5f59`) underline. Browsers cannot load a web font inside an SVG favicon, so the site ships PNGs rendered from it with Fraunces loaded: `app/icon.png` (512), `app/apple-icon.png` (180, square corners, a slightly smaller "Vm" for iOS's own rounding) and `app/favicon.ico` (16, 32, 48).
